# Research Agent Web

This is a minimal frontend implementation for the
[research-agent](https://github.com/timurci/research-agent) project, hosted on
[GitHub Pages](https://timurci.github.io/research-agent-web/).

## Tech stack
- React 19
- Tailwind CSS v4

## Status
This frontend is not yet integrated with the backend and is not fully functional
as intended. It currently displays mock data and does not collect feedback or any
user queries.
